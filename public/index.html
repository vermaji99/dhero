LeadFlow

This repo is a monorepo. Deploy the client and server folders as two separate Vercel projects, each with Root Directory set to client and server respectively.

  • Backend API is already deployed at https://dhero-server-gamma.vercel.app/api
  • Client (React + Vite SPA): Root Directory = client, env VITE_API_URL=https://dhero-server-gamma.vercel.app/api
  • Server (NestJS + Prisma / MongoDB): Root Directory = server, envs DATABASE_URL, JWT_SECRET, CORS_ORIGIN=<client-domain>

You accidentally deployed the repo root. Delete this Vercel project and create two new ones using the Root Directory setting, or run vercel from inside the client/ and server/ folders on your machine.
